# Security Policy

## Reporting a Vulnerability

Phantom Password Manager is a security-sensitive project. If you discover a security vulnerability, please report it privately by opening a [GitHub Issue](https://github.com/anomalyco/phantom-password-manager/issues) with the details. Avoid including sensitive exploit details in the public description — we will follow up to discuss next steps.

We aim to acknowledge reports within **48 hours** and will work on a fix as quickly as possible.

## Scope

This security policy covers the **latest release** of the application. Older versions may not receive security patches.

## What to Report

- Cross-site scripting (XSS) vulnerabilities
- Encryption or cryptographic weaknesses
- Authentication bypass issues
- Data exposure or leakage
- Dependency vulnerabilities with known exploits

## What to Expect

1. **Acknowledgment** — We'll confirm receipt within 48 hours.
2. **Assessment** — We'll evaluate the severity and impact.
3. **Fix** — We'll develop and release a patch. The timeline depends on severity.
4. **Disclosure** — We'll publish a security advisory after the fix is released.

## Supported Versions

Only the latest major version receives security updates. Always use the most recent release.

## Responsible Disclosure

We ask that you give us reasonable time to fix and release a patch before publicly disclosing any vulnerability. We'll credit you in the advisory if you'd like.
